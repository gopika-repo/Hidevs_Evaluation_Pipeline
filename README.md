# Dave AI Assistant Evaluation Pipeline

This is a production-grade, standalone evaluation pipeline for the AI assistant "Dave". It scores Dave's past conversations across three major dimensions: **Response Quality**, **Groundedness/Hallucination**, and **Safety**.

---

## Getting Started

### 1. Prerequisites
Ensure you have Python 3.10+ installed.

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Environment Configuration
Copy the `.env.example` file to `.env` and fill in your Gemini API key:
```bash
cp .env.example .env
```
Inside `.env`:
```ini
GEMINI_MODEL_NAME=gemini-flash-latest
GOOGLE_API_KEY=your-actual-api-key-here
LOG_LEVEL=INFO
```

---

## Running the Pipeline

To run the full end-to-end evaluation against the mock dataset:
```bash
python -m evaluation_pipeline.main
```

To run unit tests verifying the mathematical logic of the evaluators:
```bash
python -m unittest tests/test_arithmetic.py
```

---

## Output Reports

After execution, all files are saved in the `output/` directory:

1. **`evaluation_report.json`**
   - Contains a complete detailed log for every conversation evaluated.
   - Includes sub-score breakdowns, full text explanations generated by the LLM, and overall aggregated health scores.

2. **`evaluation_summary.csv`**
   - A flat summary table representing the top-line scores per conversation.
   - Ideal for quick scanning, importing into spreadsheets, or database logging.

3. **`flagged_conversations.json`**
   - Lists only the critical conversations that failed safety thresholds (Safety Score < 70) or showed unusually low groundedness (Groundedness Score < 15/30).
   - Designed for human-in-the-loop manual review priority queue.

---

## Log Files
- Detailed pipeline operations and network status are shown in stdout (and standard logger outputs).
- Raw LLM request prompt constructs, system configurations, and raw model response payloads are logged locally in `logs/llm_calls.log` for inspection.
