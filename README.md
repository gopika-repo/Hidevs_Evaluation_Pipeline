# Dave AI Assistant Evaluation Pipeline — Phase 1

This is a production-grade, standalone evaluation pipeline for the AI assistant "Dave". It scores Dave's past conversations across five major dimensions under **Phase 1 scope**:

| Dimension | Max Score | Description |
|---|---|---|
| **Response Quality** | 20 points | Correctness, helpfulness, clarity, and completeness (LLM judge) |
| **Groundedness / Hallucination** | 15 points | Claims coverage, faithfulness to context, unsupported claims, and contradictions |
| **Safety** | 15 points | Confidentiality, boundary protection, security attacks (programmatic overrides force 0 on leaks) |
| **Intent Understanding** | 15 points | Assesses if Dave correctly identified the user query category (personal, technical, platform, out of scope, ambiguous) and handled clarification properly |
| **Retrieval Quality** | 15 points | Evaluates RAG contexts via Ragas context_precision/recall, plus LLM noise & redundancy checks. Returns N/A for context-free queries |
| **Overall Health Score** | **80 points** | Combined sum of all applicable dimension scores (Phase 1 scope total) |

Memory (10 points) and User Satisfaction (10 points) are deferred for Phase 2.

## Getting Started

### 1. Prerequisites
Ensure you have Python 3.10+ installed.

### 2. Install Dependencies
```bash
pip install -r requirements.txt
pip install ragas datasets langchain-google-vertexai
```

### 3. Environment Configuration
Copy the `.env.example` file to `.env` and fill in your Gemini API key:
```bash
cp .env.example .env
```
Inside `.env`:
```ini
GEMINI_MODEL_NAME=gemini-3.5-flash
GOOGLE_API_KEY=your-actual-api-key-here
LOG_LEVEL=INFO
```

## Running the Pipeline

To run the full end-to-end evaluation against the mock dataset (including Phase 1 rescaled points, Intent, and Retrieval):
```bash
python -m evaluation_pipeline.main
```

To run unit tests verifying the mathematical logic of the evaluators:
```bash
python -m unittest tests.test_arithmetic -v
```

## Output Reports

After execution, all files are saved in the `output/` directory:

1. **`evaluation_report.json`**
   - Contains a complete detailed log for every conversation evaluated.
   - Includes sub-score breakdowns, full text explanations generated by the LLM, and overall aggregated health scores.
   - Outputs `"pipeline_phase": "phase_1"`. For context-free queries, `retrieval_quality` has `applicable: false` and `score: null`.

2. **`evaluation_summary.csv`**
   - A flat summary table representing the top-line scores per conversation.

3. **`flagged_conversations.json`**
   - Lists only the critical conversations that failed safety thresholds (Safety Score < 10.5) or showed low groundedness or misclassified intents.
